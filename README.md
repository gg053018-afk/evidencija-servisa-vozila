# Evidencija servisa vozila

Web aplikacija za evidenciju vozila, servisa, troškova i termina za sljedeći servis.

## Funkcionalnosti

- Dodavanje vozila
- Prikaz svih vozila
- Pretraga vozila
- Izmjena podataka o vozilu
- Brisanje vozila
- Dodavanje servisa za određeno vozilo
- Prikaz istorije servisa
- Izmjena servisa
- Brisanje servisa
- Evidencija troškova
- Prikaz ukupnih troškova vozila
- Unos termina za sljedeći servis
- Upozorenje kada se približava sljedeći servis
- Upozorenje kada je termin servisa prekoračen

## Tehnologije

- Python
- Flask
- SQLite
- HTML
- CSS
- Git
- GitHub

## Pokretanje aplikacije

1. Instalirati Python.
2. Instalirati potrebne Python pakete.
3. Pokrenuti `app.py`.
4. Otvoriti aplikaciju u web pregledniku.
